# Image scenery

`alpine-panorama.webp` and `harbor-panorama.webp` are original generated 360-degree
panoramas created for Throttle Formula on 31 October 2026. They are bundled locally;
the game does not depend on a remote image service. Source PNGs are retained in the
creation workspace; these WebP files contain the same imagery encoded for delivery.

No Crazy Grand Prix image or texture is included. Its publisher page was a visual
reference, not an asset source. The panoramas are displayed at infinity, with low
3D foothills, buildings, barriers and trees providing foreground depth and parallax.
